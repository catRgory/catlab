# Create a leg morphism from a discrete foot into an apex

Create a leg morphism from a discrete foot into an apex

## Usage

``` r
make_leg(schema, interface_ob, indices, apex)
```

## Arguments

- schema:

  BasicSchema

- interface_ob:

  Character: which object type

- indices:

  Integer vector: which apex parts this foot maps to

- apex:

  ACSet: the target

## Value

ACSetTransformation
