# Create a structured cospan (open system)

Create a structured cospan (open system)

## Usage

``` r
structured_cospan(apex, legs, interface_ob)
```

## Arguments

- apex:

  ACSet (the full system)

- legs:

  List of ACSetTransformations from feet into apex

- interface_ob:

  Character: which object type forms the interface

## Value

StructuredCospan
