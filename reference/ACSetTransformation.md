# ACSet transformation (natural transformation between ACSets)

ACSet transformation (natural transformation between ACSets)

## Usage

``` r
ACSetTransformation(
  components = list(),
  dom_acset = acsets::ACSet(),
  codom_acset = acsets::ACSet()
)
```

## Arguments

- components:

  Named list of integer vectors mapping parts

- dom_acset:

  Domain ACSet

- codom_acset:

  Codomain ACSet
